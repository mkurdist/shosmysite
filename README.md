# راه‌اندازی
1. `npm i && npm start` → http://localhost:3000 (بدون هیچ تنظیمی با products.json و پرداخت دمو کار می‌کند)
2. **GitHub:** پوشه را push کنید.
3. **Render:** New → Web Service → ریپو را وصل کنید. Build: `npm install` ، Start: `npm start`
   متغیرهای محیطی (اختیاری): `BASE_URL` (آدرس Render), `ZARINPAL_MERCHANT`, `ZARINPAL_SANDBOX=1` (برای تست), `SUPABASE_URL`, `SUPABASE_KEY` (service_role)
4. **Supabase:** محتوای supabase.sql را در SQL Editor اجرا کنید. محصولات را از products.json در جدول products وارد کنید (Import CSV/JSON).
5. **Uptime:** در UptimeRobot یک مانیتور HTTP روی `https://YOUR-APP.onrender.com/health` هر ۵ دقیقه بگذارید.

# پنل مدیریت
- آدرس: `/admin.html` — متغیر محیطی `ADMIN_PASSWORD` را در Render بگذارید (رمز قوی، حداقل ۱۲ کاراکتر). اختیاری: `ADMIN_SECRET` (رشته تصادفی برای امضای توکن).
- امکانات: آمار، لیست سفارش‌ها با فیلتر و تغییر وضعیت (پرداخت‌شده / ارسال / تحویل / لغو)، افزودن، ویرایش و حذف محصول.
- اگر Supabase وصل نیست، تغییرات محصولات روی دیسک موقت Render ذخیره می‌شود و با دیپلوی یا ری‌استارت پاک می‌شود؛ برای ماندگاری Supabase را وصل کنید و یک‌بار دکمه «انتقال محصولات نمونه» را بزنید.
- عکس محصول: در Supabase یک Storage bucket عمومی بسازید، عکس را آپلود کنید و لینکش را در فرم محصول بگذارید.

# رسانه (Media Library)
- در پنل مدیریت تب «رسانه»: آپلود چندتایی با کشیدن و رها کردن؛ عکس‌ها قبل از ارسال به WebP با حداکثر ۱۲۰۰ پیکسل تبدیل می‌شوند (سایت سریع می‌ماند).
- با Supabase: باکت عمومی `media` خودکار ساخته می‌شود (اسم دیگر: متغیر `SUPABASE_BUCKET`). بدون Supabase فقط برای تست محلی در پوشه `uploads` ذخیره می‌شود و روی Render پاک می‌شود.
- در فرم محصول دکمه «رسانه» را بزنید و عکس را انتخاب کنید. محصولات بدون عکس، طرح شماتیک کفش (چرم / اسپورت / کتونی) با برچسب مردانه/زنانه/بچگانه نشان می‌دهند.
